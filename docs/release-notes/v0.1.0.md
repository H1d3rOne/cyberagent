# CyberAgent v0.1.0

## Highlights

- CLI/TUI-first authorized Web/API security analysis agent.
- Deterministic `scan web` safe profile for low-risk Web/API analysis.
- Evidence-first run workspace with artifacts, findings, reports, events, and command audit logs.

## Features

- CLI commands: `version`, `doctor`, `scan web`, `report`, `replay`, `plugins list`, `plugins doctor`, `tui`.
- Run workspace with `target.json`, `scope.json`, `job.json`, `plan.json`, `events.jsonl`, `commands.log`, artifacts, evidence, findings, and reports.
- bbolt state store for Job/Plan/Step state snapshots.
- Built-in Web tools:
  - HTTP probe/fetch
  - Security header checker
  - Cookie checker
  - robots.txt / sitemap.xml fetch and parse
  - HTML extractor
  - JavaScript asset collector
  - Light JS route extractor
  - API hint detector
  - Small low-rate content discovery
  - TLS inspector
  - TCP common web port check
- Plugin MVP:
  - `nuclei-safe`: optional, disabled by default, missing dependency is skipped safely.
  - `python-js-route-analyzer`: optional offline JS artifact analyzer.
  - `ffuf-low-rate`: optional; enters plan when explicitly enabled, but safe MVP skips it pending approval/HITL execution.

## Security Boundaries

- Active scans require explicit scope.
- Scope Guard validates outbound URLs.
- External tools are disabled by default.
- Medium/high-risk or `requires_approval` steps are blocked by Risk Policy in safe profile.
- Every tool/plugin call is written to `commands.log`.

## Known Limitations

- MVP focuses on authorized Web URL / Web API safe profile only.
- TUI v1 is a read-only run viewer.
- Desktop, multi-user Web platform, Remote Runner, and long-term memory are deferred.
- LLM paths are experimental enhancements and are not required by the MVP Core runtime.
- `ffuf-low-rate` does not auto-run in safe MVP until HITL approval/resume is implemented.
