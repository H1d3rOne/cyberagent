# CyberAgent v0.1.2 API Contract

版本：v0.1.2
日期：2026-05-24
状态：草案完成；daemon read-only API 与 approval write/resume API 已实现；scan/job endpoint 待实现

---

## 1. Contract 定位

本文档定义 v0.1.2 Local Daemon / Web API Foundation 的 P0 HTTP API 草案。

目标：

```text
为 Desktop/Wails、未来 Web Console、TUI service 化和外部脚本提供稳定的本地 API 边界。
```

非目标：

```text
不定义公网 API
不定义多用户/RBAC
不定义 Remote Runner
不定义云端同步
不定义完整 Web UI
不要求本阶段提供 generated client
```

---

## 2. Base URL 与版本

默认监听：

```text
http://127.0.0.1:8787
```

API 前缀：

```text
/api/v1
```

示例：

```text
GET http://127.0.0.1:8787/api/v1/version
```

版本策略：

```text
v0.1.2 P0 固定 /api/v1。

新增字段默认向后兼容。
客户端必须忽略未知字段。
```

## 3. 认证

v0.1.2 P0 默认所有 `/api/v1/*` endpoint 都需要 Bearer token，包括 `healthz`。

Header：

```http
Authorization: Bearer <token>
```

默认 token 来源：

```text
cyberagent daemon --token-file <path>
```

安全约束：

```text
默认只监听 127.0.0.1。
默认不启用 CORS。
默认不提供 public mode。
Authorization header 不能写入 access log。
token 文件权限建议 0600。
```

未认证响应：

```json
{
  "ok": false,
  "data": null,
  "error": {
    "code": "unauthorized",
    "message": "missing or invalid bearer token",
    "details": {}
  }
}
```

## 4. 通用响应格式

成功：

```json
{
  "ok": true,
  "data": {},
  "error": null
}
```

失败：

```json
{
  "ok": false,
  "data": null,
  "error": {
    "code": "bad_request",
    "message": "invalid request",
    "details": {}
  }
}
```

约定：

```text
ok=true 时 error 必须为 null。
ok=false 时 data 必须为 null。
message 面向人类可读。
code 面向程序稳定匹配。
details 可为空对象。
```

---

## 5. 通用 HTTP Status 与 Error Code

| HTTP | code | 说明 |
|---|---|---|
| 400 | `bad_request` | 请求参数、JSON 或 query 不合法 |
| 401 | `unauthorized` | 缺少或错误 token |
| 404 | `not_found` | run/job/report/artifact 不存在 |
| 409 | `conflict` | 当前状态冲突，例如已有 running job |
| 422 | `scope_required` | 主动扫描缺少 scope |
| 422 | `policy_denied` | 策略拒绝执行 |
| 422 | `approval_required` | 需要人工审批 |
| 424 | `tool_dependency_missing` | 外部工具依赖缺失 |
| 499 | `job_cancelled` | job 被取消；若实现层不使用 499，可映射为 409/500 并保持 code |
| 500 | `internal_error` | 未分类内部错误 |
| 501 | `unsupported` | P0 明确不支持的能力 |

错误响应示例：

```json
{
  "ok": false,
  "data": null,
  "error": {
    "code": "scope_required",
    "message": "scope is required for active scanning",
    "details": {
      "field": "scope"
    }
  }
}
```

## 7. Run ID 与路径约束

P0 API path 中的 `{run_id}` 不是任意文件路径。

约束：

```text
run_id 必须解析到 daemon 配置的 runs-dir 下。
run_id 不允许包含 /、\、.. 或绝对路径前缀。
artifact/report/events 读取必须限制在该 run workspace 内。
不支持通过 API 读取任意本机路径。
```

错误：

```text
非法 run_id 返回 bad_request。
不存在 run 返回 not_found。
路径越界返回 bad_request 或 not_found，且不得读取 runs-dir 外文件。
```

## 16. Resume Approved

### 16.1 POST /api/v1/runs/{run_id}/resume-approved

当前 v0.1.2 slice 同步执行并直接返回 resumed/skipped 结果。
后续如需要长耗时恢复，可再迁移为 job manager 异步执行。

Request：

```json
{
  "operator": "local-user"
}
```

响应：

```json
{
  "ok": true,
  "data": {
    "run_id": "20260524-120000-ffuf-approval",
    "run_dir": "runs/20260524-120000-ffuf-approval",
    "resumed": ["step_optional_ffuf_low_rate_001"],
    "skipped": []
  },
  "error": null
}
```

约束：

```text
语义必须复用 cyberagent replay <run-dir> --resume-approved。
恢复执行前必须重新经过 Scope Guard。
unsupported approved step 返回明确 skipped/unsupported，不隐式执行。
resume 完成后应刷新 report 和 artifact index。
```

```json

  "target": "http://127.0.0.1:8080",
```

| `profile` | no | `safe` | P0 仅要求 safe |
| `enabled_plugins` | no | `[]` | 默认不启用外部插件 |
| `no_external_tools` | no | `true` | 默认不使用外部工具 |

```json
    "run_url": "/api/v1/runs/20260524-120000-simple-site"

  "error": null

```

约束：

```text
必须异步启动。
缺少 scope 返回 scope_required。
默认 safe profile。
```

## 19. Daemon Smoke Test 草案

完整 smoke test 文档见：

```text
docs/CyberAgent-v0.1.2-Daemon-Smoke-Test.md
```

变量：

```bash
BASE="http://127.0.0.1:8787"
TOKEN="$(cat .tmp/cyberagent-token)"
AUTH="Authorization: Bearer ${TOKEN}"
```

检查 health：

```bash
curl -sS -H "$AUTH" "$BASE/api/v1/healthz"
```

检查 version：

```bash
curl -sS -H "$AUTH" "$BASE/api/v1/version"
```

启动 scan：

```bash
curl -sS -H "$AUTH" -H 'Content-Type: application/json' \
  -d '{"target":"http://127.0.0.1:8080","scope":"127.0.0.1","profile":"safe"}' \
  "$BASE/api/v1/scans/web"
```

轮询 job：

```bash
curl -sS -H "$AUTH" "$BASE/api/v1/jobs/<job_id>"
```

读取 report：

```bash
curl -sS -H "$AUTH" "$BASE/api/v1/runs/<run_id>/report?format=json"
```

读取 artifacts：

```bash
curl -sS -H "$AUTH" "$BASE/api/v1/runs/<run_id>/artifacts"
```

读取 events：

```bash
curl -sS -H "$AUTH" "$BASE/api/v1/runs/<run_id>/events?limit=100"
```
